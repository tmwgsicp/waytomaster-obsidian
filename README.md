# WaytoMaster for Obsidian

将你在 WaytoMaster 生态产品中有权阅读的内容保存到 Obsidian。当前 0.1.1 验收版只接入 WeChatRSS，SocialRSS 和 InvestorRSS 尚未接入。

这是独立插件仓库，仅通过产品公开 API 读取内容，不包含产品服务端、采集组件或服务端凭据。尚未公开发布或提交 Obsidian 社区目录；开源许可证将在正式发布前确定。

## 使用

1. 在专用测试笔记库安装 `main.js`、`manifest.json`、`styles.css`，位置为 `.obsidian/plugins/wechatrss/`，在 Obsidian 第三方插件设置中启用。
2. 打开 WeChatRSS 插件设置，从 WeChatRSS 网页「集成中心 → API」复制自己的 API Key 和 API Secret，点击「连接并读取订阅」。这是 WeChatRSS 账号，无需登录微信。
3. 选择公众号，点击「手动同步」或「开启自动同步」。默认保存在 `WeChatRSS` 文件夹，按公众号整理，可以更改保存位置。

自动同步立即检查一次，以后每小时检查；需要保持 Obsidian 打开。「暂停」停止后续检查，已保存笔记及进度保留。重启后需要重新连接并明确开启自动同步。旧日期筛选会明确显示，可点击取消，不会静默改变范围。

## 账号、网络与数据

- 需要 WeChatRSS 账号及相应 API / 内容权限；部分能力需要付费，具体以产品网站套餐为准。插件不绕过套餐、订阅、配额或文章阅读权限。
- 仅请求 `https://wechatrss.waytomaster.com` 的身份、订阅和文章读取接口，用于同步已授权内容；不上传笔记库，不触发采集、购买或新增订阅。
- API Key / Secret 仅保存在插件运行内存中，不写入笔记、插件状态或日志。现有 API Key 不是插件专用只读授权，请勿分享；浏览器 OAuth 授权尚未接入。
- 图片保留原始远程链接，查看时可能访问图片所在服务；暂不支持离线图片。
- 无客户端遥测，不读取笔记库以外的文件。笔记和恢复进度在本地笔记库中保存，备份时保留插件 `data.json`。

## 同步行为

重复同步复用已有笔记；用户修改或正在编辑的内容不会被覆盖。网络中断后可以继续，服务限频时等待，不重复购买内容。每轮最多读取 20 页，更多内容在后续轮次继续。更改保存位置不搬迁原有笔记。

目前尚无批注回传、冲突合并或跨设备状态合并。旧服务不提供稳定账号身份时，更换 API Key 可能产生另一份同步记录，连接后会提示。

## 构建和验证

要求 Node.js 22。

```sh
npm ci
npm test
npm run build
```

构建产物位于 `dist/`，仅分发三个插件文件；`data.json`、测试数据、依赖目录不进入安装包。插件 ID 继续使用 `wechatrss`，保留既有用户安装与数据位置。

已通过同步、身份隔离、断点恢复、编辑保护和定时暂停测试。Mac Obsidian 1.14.4 已完成专用笔记库内的界面与同步流程验证；Windows 尚未实装验收。正式发布前还需完成 OAuth、安全凭据保存及双端升级验收。
